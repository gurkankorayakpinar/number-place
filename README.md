# Number Place

- Karelere eklenen numaraları değiştirmek veya silmek mümkündür.

- Hatalı seçimler, oyuna etki etmez.

- Tamamlanan 3x3 alanlar kilitlenir ve o alandaki rakamların rengi maviye dönüşür.

- Birden fazla çözüm varmış gibi bir durum oluşmasını engellemek için Recursive Backtracking algoritması kullanılmıştır.
